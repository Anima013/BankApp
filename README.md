# Bank App

A simple console-based banking application developed in C# that allows users to create deposit accounts, manage balances, and calculate interest based on the selected deposit term.

## Features

- Create new deposit accounts
- Deposit funds into an account
- Withdraw funds from an account
- Calculate interest based on deposit duration
- Display account information
- Sort accounts by balance in descending order
- Validate user input

## Interest Rates

- 3–12 months → 2%
- 13–24 months → 5%
- 25–36 months → 7%

## Technologies Used

- C#
- .NET
- Object-Oriented Programming (OOP)
